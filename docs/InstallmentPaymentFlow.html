2 · Endpoints

GET List All Installments
/api/installments Paginated (default 25). Filters: period, due_from, due_to, status, pending_verification, booking_id, project_id.
view installments
GET List by Booking
/api/bookings/{id}/installments All installments for one booking (not paginated). Optional filter: status.
view installments
GET Show Installment
/api/bookings/{id}/installments/{id} Full detail of one installment with all payments, verifier and creator info.
view installments
POST Record Payment
/api/bookings/{id}/installments/{id}/payments Body: amount, payment_date, payment_method, reference_number, receipt (file), notes.
record installment payment
POST Verify Payment
/api/.../payments/{id}/verify No body needed. Updates installment paid_amount and recalculates status.
verify installment payment
POST Reject Payment
/api/.../payments/{id}/reject Optional body: reason (max 1000 chars). Stored as rejection_reason.
reject installment payment
POST Issue Invoice
/api/.../payments/{id}/invoice Optional body: vat_rate, notes. Payment must be verified.
issue invoice
GET Download Invoice PDF
/api/invoices/{id}/download Returns binary PDF. Use responseType: 'blob' in Axios.
view invoices
